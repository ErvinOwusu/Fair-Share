# FairShare frontend

Vue 3 frontend built with Vite. Run these commands from this directory:

```sh
npm ci
npm run dev
```

Use Node.js matching `^22.18.0 || >=24.12.0`, as specified in `package.json`.

To build and preview:

```sh
npm run build
npm run preview
```

The build output is `dist/`. The current UI is a landing page; login/signup
and backend API integration are not yet implemented.

See the [repository README](../README.md) for the complete project structure,
backend setup, database migrations, and Vercel deployment instructions.
